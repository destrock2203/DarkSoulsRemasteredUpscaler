# DSRUpscaler

DLSS, FSR and XeSS for Dark Souls Remastered (DarkSoulsRemastered.exe 1.0.0.0, Oct 2022 build):
native-resolution anti-aliasing (DLAA / FSR Native AA / XeSS AA) replacing the game's TAA, frame
generation (DLSS-G, FSR frame generation or XeSS-FG, with any upscaler), sharpening (AMD RCAS, NVIDIA
Image Scaling, Laplacian) and optional DLSS 5. The frame rate unlock is zofrea1's DS1 FPS Unlock,
installed separately: with it loaded, the menu sets its limit live (`[Game] AutoFPS` / `TargetFPS`).
Based on EldenRingUpscaler. Release zip: `package.ps1`.

> **Status: untested in game.** Everything builds; the game-specific parts rest on a static analysis
> of the executable and of the game's shaders (see [src/game/dsr.h](src/game/dsr.h)). The next step
> is a run of the probe (below) to confirm what the analysis couldn't: when the TAA runs, on which
> context, how its constants are updated. Upscaling below native resolution comes after that.

In game: **Home** opens the settings, **F7** toggles the upscaler (off = the game's own TAA).

## Why a D3D12 bridge

The game renders with D3D11. DLSS could run on D3D11, but FSR 3.1 / 4, XeSS on non-Intel GPUs and
every frame generation backend are D3D12 only. So the mod creates a D3D12 device on the game's GPU
and textures both devices share, ordered with two shared fences
([src/render/bridge.h](src/render/bridge.h)). The upscalers are the Elden Ring mod's backends,
unchanged apart from the depth convention: this engine uses standard depth (1 = far).

```
DarkSoulsRemastered.exe
  └─ loads dxgi.dll from its folder (this mod), which forwards to System32\dxgi.dll (or ReShade)
       ├─ D3D11CreateDevice (import patched in DllMain) → device / context hooks, D3D12 bridge
       └─ IDXGIFactory::CreateSwapChain → the presenter's swapchain (render/presenter.h)

Frame (D3D11, immediate + 8 deferred contexts):
  velocity pass (FRPG_*_Vel)        → jitter + camera from its vertex constants
  TAA resolve (FRPG_Fil_ResolveTAA) → motion vectors + depth rebuilt (shaders/motion_vectors.hlsl)
                                      into shared textures, color copied; the resolve runs; the
                                      upscaler (D3D12) replaces its output. On a deferred context
                                      the command list is split around the upscaler.
  first HUD draw (FRPG_Menu_*)      → HUD-less image copied for frame generation
  Present                           → overlay; D3D12: frame generation tags, copy to the D3D12
                                      swapchain (owned by DLSS-G / FSR FG / XeSS-FG), Present
```

| Path | Purpose |
|---|---|
| `src/proxy/` | dxgi.dll export forwarding, shared by the mod and the probe (`proxy_host.h`) |
| `src/core/` | bootstrap, INI config, logging, crash logger, paths, frame timing |
| `src/hooks/` | MinHook wrapper, D3D11 device / context hooks (state tracking, command list splits), DXGI hooks. Vtable indices checked against the SDK at compile time (`vtable_check.c`) |
| `src/game/` | Dark Souls Remastered: findings (`dsr.h`), shader names from the game's archives (`shader_db.h`, generated by `tools/gen_shader_table.py`), RTTI lookups, the frame pacing object (`flipper.h`), the live FPS limit with DS1 FPS Unlock (`high_fps.h`, `fps_unlock_mod.h`) |
| `src/render/` | D3D12 bridge, upscaler in the frame (`upscale.h`), presenter swapchain, D3D11 helpers |
| `src/shaders/` | motion vector rebuild, full-screen copy (compiled with fxc at build time) |
| `src/upscaler/` | DLSS (Streamline), FSR (FidelityFX API), XeSS, and their frame generation |
| `src/framegen/` | frame generation backend selection |
| `src/overlay/` | ImGui settings overlay (DX11) |
| `src/probe/` | DSRProbe, the diagnostic DLL |

## Building

Requirements: Visual Studio 2022 or newer with "Desktop development with C++" (MSVC, Windows SDK,
CMake, Ninja). MinHook, Dear ImGui and stb are fetched automatically.

Run `build.bat` (or `build.bat x64-debug`). Outputs:

- `build/x64-release/dxgi.dll` + `DSRUpscaler.ini` + `DSRUpscaler/` (vendor runtimes): the mod
- `build/x64-release/probe/dxgi.dll` + `DSRProbe.ini`: the probe

The vendor SDKs (Streamline, FidelityFX, XeSS) are found in `third_party/`, or in the Elden Ring
mod's `../EldenRingUpscaler/third_party/` (see [third_party/README.md](third_party/README.md)). Each
backend builds as unavailable without its SDK.

`tools/gen_shader_table.py "<DARK SOULS REMASTERED folder>"` regenerates the shader name table from
the game's `shader/` archives (only needed if the game's shaders ever change).

## DSRProbe (run this first)

A dxgi.dll that changes nothing in the game and writes what the mod needs to know. Steps:

1. In the DARK SOULS REMASTERED folder, move ReShade's `dxgi.dll` aside if it's there (the probe
   is dxgi.dll too; `ChainLoadDXGI=ReShade64.dll` in DSRProbe.ini keeps ReShade if you rename it).
2. Copy `build/x64-release/probe/dxgi.dll` and `DSRProbe.ini` into that folder.
3. Start the game, set **Anti-aliasing: On** in the graphics options, load a save and stand
   somewhere with a view (an enemy or NPC moving in view is best).
4. Press **F10**: a trace of 2 frames is written (`DSRProbe_trace_<frame>.txt`) with PNG dumps
   (`DSRProbe_dumps/`). Wait a few seconds.
5. Set **Anti-aliasing: Off**, back in game press **F10** again.
6. Press **F11**: the engine's frame pacing switches to its 140 FPS mode; watch the frame rate for
   20 seconds (the log reports it every 10 s), then press F11 again to go back.
7. Quit. Send `DSRProbe.log`, the `DSRProbe_trace_*.txt` files and the `DSRProbe_dumps` folder.

Optional, to locate a setting in memory: press **F9**, change one option (e.g. Anti-aliasing),
press F9, change it back, press F9: the addresses that followed are logged.

## Installing the mod

1. Copy `dxgi.dll`, `DSRUpscaler.ini` and the `DSRUpscaler` folder into DARK SOULS REMASTERED.
2. Keep the game's Anti-aliasing **On** (the upscaler replaces its TAA).
3. Check `DSRUpscaler.log`. To uninstall, delete `dxgi.dll`.

ReShade: rename its dxgi.dll to `ReShade64.dll` and set `ChainLoadDXGI=ReShade64.dll`.
Offline play only: don't take a modified game online.
